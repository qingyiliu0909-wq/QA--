# 执行可执行性验证

## 本步目标

验证其他 Agent 能否按照工作流步骤独立执行。

## 执行前必读

- [[../专项知识/01_验证核心/Repo扩展专项_工作流设计原则]]
- [[../../知识/工作流目录架构规范]]

## 必需输入

- 工作流 WORKFLOW.md 文件
- 相关标准步骤文件

## 建议动作

1. 读取工作流文件，提取所有步骤引用
2. 检查每个步骤是否有以下契约项：
   - 本步目标
   - 必需输入
   - 产出物
   - 完成证据
   - 失败自愈入口
3. 检查 Wiki Link 是否可用（目标文件存在）
4. 检查知识链接是否可用
5. 模拟另一个 Agent 执行流程，识别理解障碍

## 验证清单

| 检查项 | 合格标准 |
|--------|----------|
| 步骤有"本步目标" | 一句话说明目标 |
| 步骤有"必需输入" | 明确需要什么材料 |
| 步骤有"产出物" | 明确输出什么 |
| 步骤有"完成证据" | 有检查项或标志 |
| 步骤有"失败自愈入口" | 失败时有恢复路径 |
| Wiki Link 可用 | 目标文件存在 |

## 产出物

- 可执行性验证报告
- 缺失的契约项清单
- Wiki Link 可用性报告

## 完成证据

- [ ] 已检查所有步骤的契约项
- [ ] 已验证所有 Wiki Link
- [ ] 已记录缺失项

## 失败自愈入口

- 若 Wiki Link 断裂 → 提示修复链接
- 若缺少契约项 → 提示补充契约内容
- 若步骤描述模糊 → 标注为"需人工补充"
