# 执行可复用性验证

## 本步目标

验证工作流是否可以在不同场景下复用，参数是否可配置，输出是否可预测。

## 执行前必读

- [[../专项知识/01_验证核心/Repo扩展专项_工作流设计原则]]

## 必需输入

- 工作流 WORKFLOW.md 文件
- 标准步骤文件

## 建议动作

1. 检查工作流是否有明确的"最小输入"定义
2. 检查是否有默认参数或默认目标
3. 检查输出结构是否可预测（有模板或规范）
4. 检查失败时是否有恢复机制
5. 构造不同输入场景测试复用性

## 验证清单

| 检查项 | 合格标准 |
|--------|----------|
| 有"最小输入"定义 | 明确最少需要什么 |
| 有默认目标/参数 | 用户不指定时有默认行为 |
| 输出结构可预测 | 有输出规范或模板 |
| 失败可恢复 | 有失败自愈入口 |

## 产出物

- 可复用性验证报告
- 参数配置完整性报告
- 失败恢复机制报告

## 完成证据

- [ ] 已检查最小输入定义
- [ ] 已检查默认参数
- [ ] 已检查输出结构
- [ ] 已检查失败恢复

## 失败自愈入口

- 若缺少最小输入定义 → 提示补充
- 若缺少默认参数 → 标注为"需补充默认值"
- 若失败无法恢复 → 提示添加恢复入口
