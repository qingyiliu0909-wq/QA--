# 确认验证范围

## 本步目标

明确验证对象和验证维度，避免重复验证或遗漏验证。

## 必需输入

- **验证范围**：
  - 单个工作流（指定工作流名称，如"性能分析"）
  - 某个类别（指定类别名称，如"性能与稳定性"）
  - 全部工作流（验证所有类别下的所有工作流）

- **验证维度**（可多选）：
  - 路由命中验证
  - 可执行性验证
  - 可复用性验证
  - 质量门禁验证

## 默认行为

当用户未明确指定时：
- **验证范围**：单个工作流（从用户请求中提取工作流名称）
- **验证维度**：全部维度（路由+可执行性+可复用性+质量）

## 建议动作

1. 从用户请求中提取验证范围
2. 确认验证维度（默认：全部）
3. 列出待验证的工作流清单
4. 确认输出目录

## 产出物

- 验证配置清单
- 待验证工作流列表
- 输出目录路径

## 完成证据

- [ ] 已明确验证范围（单工作流/类别/全部）
- [ ] 已明确验证维度（至少1个）
- [ ] 已生成待验证工作流列表
- [ ] 已准备输出目录

## 失败自愈入口

- 若工作流名称不存在 → 列出所有可用工作流，提示用户选择
- 若类别不存在 → 列出所有可用类别，提示用户选择
- 若输出目录创建失败 → 使用临时目录
